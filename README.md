# LTC Player

動画のキュー作成とLTC（音声タイムコード）に同期した再生に対応するWindows用プレイヤーです。指定したディスプレイへ映像を出力できます。

MP4/H.264、MOV/HAP・HAP Qに対応しています。動画ごとに開始タイムコードを設定し、受信したLTCに応じて映像を切り替えます。
