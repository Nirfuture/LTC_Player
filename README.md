# LTC Player

LTC Playerは、LTC（音声タイムコード）に合わせて動画を再生し、外部ディスプレイへ映像を出力するWindows用ツールです。複数の動画をキューに登録し、動画ごとに再生を開始するタイムコードを指定できます。

MP4/H.264、MOV/HAP・HAP Qに対応しています。
