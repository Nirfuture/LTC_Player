# 操作ガイド

[クイックスタート](QUICKSTART.md) · [対応環境](COMPATIBILITY.md) · [困ったとき](TROUBLESHOOTING.md)

## 画面と同期表示

キュー一覧で動画と開始TCを管理し、プレビューで出力映像を確認します。映像と音声の状態表示は、共通時計に対する内部の位置差を示します。

| 表示 | 意味 |
|---|---|
| 遅延なし | 内部で測定した位置差が許容範囲内 |
| ○ms遅れ／先行 | 許容範囲を超えるずれが継続 |
| 確認中 | 状態の変化を確認中 |
| 準備中／再同期中 | 再生開始や復旧の準備中 |

物理ディスプレイの表示時刻や、スピーカーから実際に鳴る時刻を測定する表示ではありません。

> 画像挿入位置：メイン画面と映像・音声の状態表示

## キューの編集

動画は一覧へのドロップ、または「キュー追加」で登録します。追加直後の開始TCは0です。同じ開始TCの行を同時に有効にはできません。

区間が重なる場合は、後から始まる動画を優先します。その動画が終了しても、前の動画には戻りません。再生対象のない区間は黒になります。

- 「複製」の行は元の開始TCを引き継ぎ、無効状態で追加されます。
- 左端のハンドルで表示順を変更します。青い線が挿入位置です。表示順を変えても、開始TC・再生順・再生中の映像は変わりません。
- ファイル名の右クリックから、エクスプローラーで保存場所を開けます。
- 「エラー」欄にマウスを重ねると、詳細を確認できます。

外部映像出力中は編集できません。

## 手動再生とLTC同期

行の選択で先頭映像を準備し、▶で手動再生します。

| 操作 | 動作 |
|---|---|
| ▶ | 再生。一時停止後は続きから、停止・終端後は先頭から |
| Ⅱ | 現在位置で一時停止 |
| ■ | 停止し、最後の映像を保持 |
| シークバー | 再生位置を変更 |

LTC同期中と外部映像出力中はシークできません。LTC受信中はLTCを優先し、手動再生はできません。

LTC入力が途切れると、設定した補間時間の後に映像を保持し、音声を無音にします。初期設定は0.1秒です。LTCが復帰すると、その時刻へ同期します。

未受信・受信途絶中は手動再生できます。外部映像出力中は、有効なキューを先頭から手動再生できます。入力エラー中は新たな手動再生を開始できません。

## 音声

音声は内容確認用で、本番音声出力の保証対象ではありません。

**音声は起動時OFFです。** 出力先と音量は保存しますが、ON状態は復元しません。

- スピーカーボタンOFF：音声出力を停止
- 音量0：無音のまま再生位置へ追従
- 一時停止・停止・終端・キュー外：無音
- 外部映像の開始・停止、蓋絵の切り替え：音声は継続

出力先はON時の機器に固定します。「システム既定」も、途中で別の機器へ自動転送しません。出力先は音声OFFで変更してください。機器切断などのエラー後は、接続を確認してOFF→ONで再試行します。

開始時に解析・復号などの準備待ちが生じる場合があります。準備後は共通時計の現在位置へ追従します。開始までの待ち時間と、開始後の同期状態は別です。

## 外部映像とプレビュー

プレビューは出力キャンバス全体を表示します。動画のアスペクト比を保ち、余白は黒になります。

外部出力の開始・停止は再生位置や蓋絵のフェードをリセットしません。出力停止の確認を取り消した場合は、出力を継続します。

出力先の切断・表示構成変更で外部出力が停止した場合は、接続と設定を確認して「出力開始」で再開します。別画面へ自動で出力し直しません。接続変更に伴う一時的な音切れは発生する場合があります。

全画面出力が不安定な場合は、出力を停止し、設定の表示方式を「互換（BitBlt）」へ変更します。

## 蓋絵

メイン画面の「蓋絵」でPNG/JPEGを登録・解除し、「蓋絵を表示」「映像に戻す」で切り替えます。未登録の場合は黒です。

切替時間は0〜60秒で、0秒は即時です。表示中も裏で映像・音声の再生は続きます。画像の登録・解除は外部映像出力停止中に行います。

画像パスと時間は保存しますが、蓋絵の表示ON状態は復元しません。

> 画像挿入位置：蓋絵の登録・切り替え・切替時間

## 設定の適用

「適用」は変更を反映し、パネルを開いたままにします。「閉じる」は未適用の変更だけを破棄します。変更した項目とタブには印が付きます。円形矢印は機器一覧の再読み込みです。

外部映像出力中はLTC入力と映像設定を変更できません。音声出力先は音声OFFで変更できます。

保存した映像出力先が未接続でも、別画面へ自動変更しません。入力・音声の設定はその状態でも変更できます。

## 保存と持ち運び

「保存」「読込」で、キュー構成をJSONへ保存・復元します。

**上演データの自動保存・前回復元はありません。通常起動時はテスト動画4本に戻ります。**

| 保存対象 | 保存先・扱い |
|---|---|
| キュー、開始TC、有効状態 | 「保存」で作成するJSON |
| 入出力設定、音量、蓋絵の画像パスと時間 | アプリの設定ファイル |
| 動画・蓋絵の画像 | 元の素材ファイル。JSONには含まれない |
| 音声ON・蓋絵表示ON | 起動時にOFFへ戻る |

相対素材パスはJSONの位置を基準に解決します。別PCへ移す場合はJSONと素材をまとめてコピーし、素材の参照先と入出力機器を確認してください。

## 同梱素材でのLTC入力

同梱動画の開始TCは5秒・20秒・35秒・50秒です。

`TestMedia/LTC_29.97DF_from-zero.wav`をPC内で使う場合は、ループバック機能や仮想オーディオケーブルを通してLTC入力へ戻します。LTC形式は29.97 DFです。動画の確認トーンはLTC信号とは別です。
