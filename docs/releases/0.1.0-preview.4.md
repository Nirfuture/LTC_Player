# 0.1.0-preview.4 配布前の確認記録

## 変更

- 本番出力の全体像を保ち、出力先の縦横比に合わせてプレビュー枠を配置。
- 出力先と動画の解像度・縦横比を併記。
- 「配信」を「出力開始／出力停止」に変更。
- 表示フレーム数を通常画面から外し、スキップフレーム数と説明を表示。

動画だけを拡大する試作は採用していません。映像の復号・描画内容と、本番出力の余白は変更していません。

## 確認

1080×1920（9:16）と3840×2160（16:9）の両出力先で、1920×1080（16:9）のHAP動画を出力し、出力枠の比率・領域内への配置・解像度表示・ボタンとカウンターの文言を確認しました。実画面でも縦向き出力の余白と動画の関係を確認しています。

出力操作9件、UI11件、追加機能5件、プレビュー・編集12件の回帰試験も通過しました。

## 既知の制約

- LTC受信再開後、映像再開まで約2秒かかる事例を確認しています。固定の待ち時間ではなく、再開時に復号処理とHAP解析・索引を作り直す実装が主因と考えられます。この版では短縮していません。
- 未署名。Smart App Controlが有効な環境では起動をブロックされる場合があります。
- 物理ディスプレイ上の同期精度、別PC、長時間運用は未確認です。
- 旧単体再生エンジンのPTS整合試験は、[前版までの確認記録](0.1.0-preview.2.md)のとおり保留です。
