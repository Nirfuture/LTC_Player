# 困ったとき

## Windowsに起動をブロックされる

現在の配布版は未署名のため、Smart App Controlが有効な環境では起動をブロックされる場合があります。

## 起動しない

ZIPをすべて展開し、展開先の`LtcPlayer.Avalonia.exe`から起動してください。

フォルダー内のファイルを移動・削除した場合は、ZIPを展開し直してください。

あわせて、Visual C++ x64ランタイムがインストールされているか確認してください。

## 動画を読み込めない

次を確認してください。

- 動画ファイルが移動・削除されていないか
- [対応する動画形式](COMPATIBILITY.md)か
- FFmpeg・ffprobeをPATHに登録しているか

一覧にエラーが表示されている場合は、「エラー」欄にマウスを重ねると内容を確認できます。

## LTCを受信できない

「設定」で次を確認してください。

| 項目 | 確認すること |
|---|---|
| LTC入力 | 接続した入力機器を選んでいるか |
| 入力チャンネル | LTCが入っている側のLまたはRを選んでいるか |
| LTC形式 | 送信元のフレームレート・DF/NDFと一致しているか |

送信元の出力、ケーブル、入力機器の接続と入力レベルも確認してください。

画面左上が`--:--:--:--`の場合は、まだLTCを受信していません。表示が薄くなっている場合は、入力の喪失またはエラーが発生しています。

## 「出力開始」を押せない

ボタンの下に表示される理由を確認してください。

| 原因 | 対処 |
|---|---|
| キューがない | 動画を追加する |
| すべてのキューが無効 | 使用する行の「有効」にチェックを入れる |
| 開始TCが重複している | 開始TCを変更するか、不要な行を無効にする |
| 開始TCが不正 | 選択したLTC形式で入力できる値に直す |
| 動画にエラーがある | 一覧の「エラー」欄を確認する |
| 出力先が未接続 | ディスプレイを接続し、「映像出力」を選び直す |

## 黒画面になる

次の場合は黒画面になります。

- まだLTCを受信していない
- 最初の動画の開始TCより前
- 動画が終了し、次の動画が始まるまでの間

動画が表示されるはずの時刻でも黒い場合は、開始TC・動画の長さ・「有効」のチェックを確認してください。

## 全画面出力が不安定になる

出力を停止して「設定」→「表示方式」を「互換（BitBlt）」に変更し、「適用」を押します。初期値は「標準（Flip）」です。現在の方式はメイン画面にも表示されます。

互換方式では負荷や表示遅延が変わる可能性があります。使用する環境で同期を確認してください。

## 映像が止まったままになる

LTC入力が途切れると、設定した補間時間の後に最後の映像を保持します。初期設定は0.5秒です。

タイムコード表示と、LTC入力機器の接続を確認してください。

## 音が出ない

動画音声はプレビューでのみ再生されます。

プレビューで音が出ない場合は、次を確認してください。

- アプリの音量とミュート
- Windowsの既定の音声出力先と音量
- 動画の音声形式がAAC・PCM系か

## 編集や設定変更ができない

出力中はキューの編集や設定変更ができません。「出力停止」から出力を停止してください。

## 前回のキューが表示されない

前回のキュー構成は自動で復元されません。「読込」から保存したJSONファイルを開いてください。

## 設定をリセットする

1. アプリを終了します。
2. `LtcPlayer.Avalonia.exe`と同じフォルダーにある`phase2-settings.json`を別の名前に変更します。
3. アプリを起動し、入出力を設定し直します。

## ログを開く

エクスプローラーのアドレスバーに、次を入力します。

```text
%LOCALAPPDATA%\LtcPlayer\logs
```

ログには機器名や動画のパスが含まれる場合があります。共有する前に内容を確認してください。

ログは自動削除されません。1セッション8 MiB、合計256 MiBの記録上限に達すると追加の記録が止まります。不要な古いログは削除してください。
