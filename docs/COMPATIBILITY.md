# 互換性と依存関係

| 項目 | 配布候補 | 確認範囲 |
|---|---|---|
| OS/CPU | Windows 11 x64 | この1台で確認。ARM64/Windows 10/macOS/Linuxは対象外 |
| .NET | 10.0.14を同梱 | SDK10.0.403で生成。元の.NET8は別保存 |
| GPU | D3D11ハードウェア/BC1・BC3対応 | GPUなし、RDP、仮想環境、他社GPUは未検証 |
| C++ | v14 x64動的ランタイム | 別途導入が必要 |
| FFmpeg | 外部ffmpeg/ffprobe | このPCの6.0 fullで試験。古い版の固定配布はしない。別バージョンは再試験が必要 |
| 入力 | WASAPI共有モード | UR22CのL/29.97DFは過去の実受信あり。今回の回帰は合成入力 |
| 表示 | 複数ディスプレイ | 開始時に指定画面の接続を確認。抜き差し中の継続保証なし |
| 音声 | AAC/PCMプレビュー | 既定Windows音声出力へ48kHzステレオ。動画内音声の本番送出なし |

このPCでの成功を全機種への保証としない。HDR、色管理、複数GPU、可変リフレッシュ、排他オーディオ、8K素材の実用性能は未評価。映像とLTCの光学的同期精度、長時間稼働、他PCでの新規展開が未確認なので、まず限定テストとして使う。

SDK・ランタイム・ドライバー・FFmpegは各提供元の保守情報に従って更新し、更新後は回帰試験を行う。
